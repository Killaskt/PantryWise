# **App Name**: PantryWise

## Core Features:

- Pantry Builder: Manually add ingredients and quantities to a virtual pantry.
- Smart Recipe Suggestions: Suggest recipes based on pantry contents and user's dietary goals, using an AI tool to determine the best matches.
- Recipe Display: Display recipes with clear ingredient lists and instructions.

## Style Guidelines:

- Primary color: Earthy green (#386641) to convey health and nature.
- Secondary colors: Light beige (#EADEDA) and soft brown (#9A8249).
- Accent: Mustard yellow (#FFB703) for a pop of warmth and to highlight key actions.
- Clean and readable font for recipe instructions.
- Simple, line-based icons for pantry items and recipe categories.
- Clean, card-based layout for recipe presentation.
